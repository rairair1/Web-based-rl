# Web-based RL

Exploring how to bring RuneLite's plugin system to phones and handheld devices through
the browser, with touch controls modelled on the official OSRS mobile client.

- **[Feasibility study](docs/feasibility.md):** why a direct browser port isn't viable,
  and the recommended path: stream real, unmodified RuneLite to a touch-first web app,
  with saved profiles for settings and plugins.
